SCOOBY-DOO: RE-MASKED
A PC port of Scooby-Doo! Unmasked (GameCube, USA) with widescreen, up to 4K and 120 fps. Made by JosiahG.

You need your own copy of the game: a dump of the USA GameCube disc (G5DE78) as a .iso, .gcm or .ciso file.
No game data is included.

1. Run "Scooby-Doo Re-Masked Launcher.exe".
2. On the Play page choose your disc image. The launcher copies the game files into the Disc folder once
   (the image file is not needed afterwards).
3. Pick display options on the Display page, then press PLAY.

In game: F10 = settings menu (resolution, picture shape, controls, audio), F11 = fullscreen / window.
Keyboard: WASD move, arrows camera, Space A, Left Shift B, R X, F Y, C Z, Q/E L/R, Enter Start, I J K L D-pad.
Gamepads work right away.

Saves are kept in Play\UserData. Mods go in Play\UserData\mods (see the launcher's Mods page).
